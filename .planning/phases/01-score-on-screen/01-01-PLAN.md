## Facts pinned by planning-time probes (opensheetmusicdisplay@2.1.2, jsdom 29.1.1, Node v24.11.1)

These were executed against the real bundle during planning; write code to them, do not re-derive.

- OSMD `Fraction` values (`VoiceEntry.Timestamp`, `Note.Length`, `SourceMeasure.Duration`, `SourceMeasure.AbsoluteTimestamp`) are in whole-note units. Quarter-note beats = `GetExpandedNumerator() * 4` over `Denominator`, then reduce by gcd. MuseScore exports arrive unreduced (`12/8`, `4/8`); reduction is mandatory for stable ids.
- `note.halfTone` for middle C (MusicXML `<step>C</step><octave>4</octave>`) is `48`; MIDI note number = `halfTone + 12` (F#5 → 66 → 78, Eb3 → 39 → 51).
- `note.Pitch.ToStringShort(3)` returns scientific names with the written accidental: `C4`, `F#5`, `Eb3`. The `3` equals `opensheetmusicdisplay.Pitch.OctaveXmlDifference`.
- `staffEntry.ParentStaff.Id` is the MusicXML `<staff>` value (1 or 2) and defaults to 1 when the element is absent. `voiceEntry.ParentVoice.VoiceId` is the literal MusicXML `<voice>` value (MuseScore uses 1 for staff 1 and 5 for staff 2).
- `measure.MeasureNumberXML` is the literal `<measure number="">` attribute. `measure.ActiveTimeSignature.Numerator/Denominator` hold beats/beat-type unreduced (`4/4`, `3/4`, `5/4`).
- A chord is one `VoiceEntry` with several `Notes` in document order. Rests are `Note` objects with `isRest() === true`. A tie is `note.NoteTie` (a `Tie` object shared by all notes of the tie); the start note satisfies `note.NoteTie.StartNote === note`; the `TieTypes` enum is unrelated (guitar articulation) and must not be consulted.
- The UMD bundle at `https://cdn.jsdelivr.net/npm/opensheetmusicdisplay@2.1.2/build/opensheetmusicdisplay.min.js` assigns `window.opensheetmusicdisplay` when loaded by a classic script tag; it exports `OpenSheetMusicDisplay`, `Fraction`, `Pitch`. Under Node the same file is `require("opensheetmusicdisplay/build/opensheetmusicdisplay.min.js")`.
- `osmd.load(content)` accepts a UTF-8 string, a `Blob`, or a `File` (read via `readAsArrayBuffer`, binary-safe, `.mxl` detected internally). `osmd.EngravingRules.GNote(note)` returns the `GraphicalNote`; its `getSVGGElement()` is `vfnote[0].getAttribute("el")`, which is only set by a real `render()` in a browser (null under jsdom), and is replaced on every re-render.
- `render()` under jsdom throws `HTMLCanvasElement's getContext()` — tests must never call `render()`; `load()` alone populates `osmd.Sheet`.
