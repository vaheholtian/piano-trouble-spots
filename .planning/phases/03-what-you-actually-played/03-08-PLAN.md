   - (a) Pair equal pitches as a multiset. Those noteheads are played, each taking the earliest unused seq of its pitch.
   - (b) Let S' be the remaining slot noteheads (sorted by MIDI, then noteId) and T' the remaining token notes (the multiset of pitches, duplicates included, in seq order). Let k = min(|S'|, |T'|). The pitch cost is k × substitution + (|S'| − k) × deletion + (|T'| − k) × insertion. It is independent of which pairing is chosen.
   - (c) Define D(A, B) as the minimum total semitone distance over matchings of size min(|A|, |B|) between the sorted pitch lists A and B. Compute it with the order-preserving DP: with the shorter list as rows, M[i][j] = min(M[i][j−1], M[i−1][j−1] + |a_i − b_j|), M[0][j] = 0, and infinity when j < i. This is exact because points on a line always have an optimal matching that preserves order. Leave a comment stating this argument. C* = D(S', T').
   - (d) For each notehead s in S', compute the forced cost of each candidate label:
